# Report source

NeurIPS 2025 style (`neurips_2025.sty`, used with the `[final]` option so the author names are shown;
the conference footer is replaced by a course-project notice in `main.tex`). Build with:

```bash
latexmk -pdf main.tex
```

or upload this folder to Overleaf. The figures are in `figs/`; they were made from saved try-on runs
(`outputs/runs/`, not in the repository) and app screenshots.
